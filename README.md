## Compilação e execução

Para compilar um arquivo C utilizando o GCC:

```bash
gcc arquivo.c -o programa
```

Para executar no Linux:

```bash
./programa
```

No Windows, dependendo do ambiente utilizado:

```bash
programa.exe
```
